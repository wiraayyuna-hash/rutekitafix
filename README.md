# RuteKita (Laravel)
Jalankan `./setup.sh`, buka http://127.0.0.1:8000
- Toko (e-commerce): `/` katalog > detail > booking > upload bukti DP > ulasan
- Partner dashboard: `/partner` (partner@rutekita.test / password)
Alur: Booking (Menunggu Konfirmasi) > Terima > Customer upload DP (Menunggu Cek DP) > Verifikasi > Serah Terima Kunci > Unit Kembali > saldo masuk (komisi 10%). Cash garasi: lewati DP.
